# Atualização dos dados

## Atualizar planilhas

Substitua ou atualize a planilha principal diretamente dentro da pasta correspondente:

- `dados/17. Atualização de SCAs/1. Nova Mutum`
- `dados/17. Atualização de SCAs/2. Rondonópolis`
- `dados/17. Atualização de SCAs/3. Rio Verde`

## Atualizar imagens

Adicione, substitua ou remova imagens JPG, JPEG, PNG ou WEBP em `1. Imagens/[Área]`. Mantenha `Projeto` ou `Obra` no nome do arquivo para a classificação automática.

## Atualizar documentação LO

Substitua ou atualize a planilha dentro de `3. Documentações LO` da unidade correspondente.

## Histórico

`2. Histórico SCAs` não alimenta o dashboard e serve somente para armazenamento.

## Publicar

Faça commit e push no GitHub. O workflow processará as fontes e atualizará o GitHub Pages automaticamente.
